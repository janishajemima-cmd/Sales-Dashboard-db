# Power BI Sales Performance Dashboard
Sales Performance Dashboard using Power BI, DAX, Power Query, and data visualization.


## Project Overview
An interactive Power BI dashboard designed to analyze sales performance, revenue trends, product performance, and regional sales.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization

## Key Features
- Sales and revenue KPI tracking
- Sales trends over time
- Product and category performance
- Regional sales analysis
- Interactive filters and slicers
- Year-over-year performance analysis, if implemented

## Files Included
- Power BI dashboard (.pbix)
- Dashboard screenshots
- Sample dataset, if appropriate and permitted

## Business Value
Helps users monitor sales performance, identify trends, and compare product and regional performance to support business decisions.

## Disclaimer
Portfolio project for educational and demonstration purposes. Only approved sample data is included.
